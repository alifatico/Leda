# Preventivissimo — notes for future sessions

- Next.js 16 (App Router, Turbopack, `cacheComponents: true`), React 19, Tailwind v4, TypeScript strict.
- No database by design. Browser localStorage holds quotes; Stripe holds purchases; `src/lib/license.ts` signs HMAC tokens that prove entitlement.
- `src/lib/quote/calc.ts` is the fiscal engine: change it only with a matching test in `tests/calc.test.ts`.
- PDF = `src/lib/pdf/QuoteDocument.tsx` (react-pdf); `src/components/QuotePreview.tsx` must stay its visual twin.
- UI strings live in `src/lib/i18n/dict.ts` (`it` is the source; `en` is type-checked against it). Document labels (inside the PDF) are in `src/lib/quote/labels.ts`.
- Prerendered pages must not call `Date.now()` / `crypto.randomUUID()` during render (Cache Components). Use the sample quote with fixed ids/timestamps, or defer to effects.
- ESLint runs the React Compiler rules: no `setState` synchronously inside effects (use lazy init, `useSyncExternalStore`, or defer to a microtask), no components defined inside components.
- Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
- Env vars are read only through `src/lib/env.ts`.
- Sharing ("Invia al cliente") is the only server-side state: `src/lib/store.ts` (Upstash REST or in-memory with `SHARE_STORE=memory`) + `src/lib/share.ts`. Public page `/p/[id]`, APIs under `/api/share`. Hidden when no store is configured.
- `src/lib/professions.ts` holds the SEO pages' content and templates; sample quotes there must stay deterministic (fixed ids and timestamps) because `/preventivo/[slug]` is prerendered.
- Comparison table and pricing copy in `dict.ts` cite competitor list prices checked in October 2026 (see `docs/COMPETITORS.md`); update both when prices change.
- Production runs on Vercel (team `alifaticos-projects`, project `preventivo-lampo`, https://preventivo-lampo-amber.vercel.app, functions in `fra1`); production branch is `master`, which auto-deploys on push. Standing authorization (12 October 2026): after every production deploy, fast-forward `master` to the deployed commit and push it, without asking again; work still happens on the session branch. Stripe live catalog ids, env vars already set and what is still missing are listed in `docs/LAUNCH.md`.
- The product name lives in `src/lib/brand.ts` (`BRAND`, "Preventivissimo" since 12 October 2026; `APP_ID` is the internal slug in Stripe metadata); never hardcode it. The old name "Preventivo Lampo" belongs to an unrelated app; domains, Stripe names and the Vercel project name are still to be aligned, see `docs/LAUNCH.md`.
- Fiscal regimes: `regimeForfettario`, `prestazioneOccasionale` (no VAT number: no VAT, withholding, no rivalsa) and `rivalsaKind` ("inps" is withheld, "cassa" is not) are all handled in `calc.ts`; the regime select is in `OptionsForm.tsx`.
- SEO content pages: `/strumenti/*` calculators and `/preventivo-forfettario`, `/preventivo-prestazione-occasionale`, `/come-fare-un-preventivo` use `src/components/ContentPage.tsx` + `FiscalCalculator` (deterministic quote, reuses `computeTotals`). Query presets for the builder: `src/lib/quote/preset.ts`.
- Client address book: `clientsStore` in `src/lib/storage.ts` keeps one entry per quote (so autosave never stores half-typed names) and survives quote deletion; `src/lib/clients.ts` dedupes by name and searches (tests in `tests/clients.test.ts`). The autocomplete is `ClientNameField` in `PartyForm.tsx`; the Builder passes `book` only for the client, never for the sender.
- Business-register lookup: `src/lib/company.ts` (server-only), three providers chosen by `companyEnv.provider()` in `env.ts`. Default with no token is VIES (free EU VAT register, by VAT number only, UI mode "vat": `VatLookupField` in `PartyForm.tsx` fills the card when 11 digits are typed; `src/lib/vat.ts` is the browser-safe digit extractor). Apify is used only with `COMPANY_LOOKUP=apify` because a run takes tens of seconds. openapi.com (`OPENAPI_COMPANY_TOKEN`, a 24-hex-character token from the console with the IT-search and IT-start scopes; the 32-character account APIKey is refused): `IT-search?autocomplete=…&dataEnrichment=name` while typing, `IT-start/{id}` on pick, UI mode "autocomplete"; `OPENAPI_COMPANY_SANDBOX=1` switches to test.company.openapi.com, which needs a sandbox token and answers only for its example companies. Apify (`APIFY_TOKEN`, actor `jungle_synthesizer~italy-registroimprese-bilanci-scraper`): the search starts a run and returns `{ runId }`, the browser polls `/api/company/run/[id]?q=` until `{ hits }` (each hit carries its `party`), UI mode "on-demand" (button, `startManualSearch` in `ClientNameField`). Both: in-memory cache, daily cap of upstream calls (`COMPANY_LOOKUP_DAILY_LIMIT`: 300 Apify, 400 openapi, 2000 VIES by default). `COMPANY_LOOKUP=mock` serves five canned companies (`COMPANY_LOOKUP_MODE=on-demand` to try the run flow) for local work and the Playwright checks. `publicConfig().companyLookup` is the mode ("off" hides the feature). Tests in `tests/company.test.ts` (fetch is stubbed).
- Document look: `quote.design` (`QuoteDesign` in `types.ts`, zod in `schema.ts`), resolved by `resolveDesign()` in `src/lib/quote/styles.ts`. Six style presets, each with its own page structure and typeface (`classico` letterhead / Libre Franklin, `moderno` full-bleed hero band with the amount due / Manrope, `essenziale` swiss monochrome with the subject as headline / Inter, `elegante` centred masthead with double rules / Lora + Playfair Display, `compatto` dense with a left stripe / IBM Plex Sans Condensed, `studio` fixed colour sidebar / Space Grotesk), are tokens (`layout`, `font`, `display`, `radius`, `tableHeader`, `zebra`, `numbered`, `clientCard`, `payable`, `heroTotal`, `monogram`) read by both `QuoteDocument.tsx` and `QuotePreview.tsx`, which must stay structurally identical. `src/lib/quote/palette.ts` derives `tint`, `line`, `deep` and `onAccent` from `branding.color`, so a light brand colour still gets readable text. The final amount is always highlighted (net payable when there is a withholding, else the total). Editor: `src/components/builder/DesignForm.tsx`; saved templates: `templatesStore` in `src/lib/storage.ts`. Everything in the editor is free; only the watermark is paid.
- Document typefaces (12 October 2026): static OFL TTFs in `src/lib/pdf/fonts/` (its README lists the licences), registered on first use by `pdfFamily()` in `src/lib/pdf/fonts.ts`, which falls back to Helvetica/Times with a console warning when the files are missing; `next.config.ts` (`outputFileTracingIncludes`) keeps the folder in the PDF routes' serverless bundles. The preview loads the same families from Google Fonts in `src/lib/fonts.ts` (`DOC_FONT_FAMILY`), which also owns the UI's Inter. Only the weights listed in `fonts.ts` exist, and italic only for Lora and Playfair (the masthead layout): asking react-pdf for a missing `fontStyle` throws.
- react-pdf gotchas: the footer must stay anchored with `top` (A4 height) rather than `bottom`, because with lineHeight on the Page a bottom-anchored fixed block lands off the sheet; every `Text` whose size differs from the page's needs its own `lineHeight` (unitless values resolve against the declaring element's size, so a title would inherit the body's line box); absolute views are positioned from the page edge, which is how the hero band, the stripe and the sidebar bleed (`fixed` + `top: 0, height: A4`); `minPresenceAhead` did not keep the notes headings with their text, so short note sections use `wrap={false}` instead.
- Motion (12 October 2026, after Emil Kowalski's design-engineering skill, github.com/emilkowalski/skill): tokens `--ease-out` / `--ease-in-out` / `--ease-drawer` in `globals.css` override Tailwind's `ease-out` / `ease-in-out`; helper classes `pressable` (press feedback, used by `Button` and icon buttons), `enter-fade` / `enter-rise` / `enter-pop` (one-off entrances via `@starting-style`), `modal-overlay` / `modal-panel` (the `Modal` stays mounted while `data-state="closing"` plays; bottom sheet under 640px). Only transform and opacity move, nothing keyboard-driven animates, `prefers-reduced-motion` keeps the fades and drops the movement. Toasts are Sonner (`Toaster` + `useToast().show` in `ui.tsx`), offset by `--bar-h`, the measured height of the builder's action bar (also the page's bottom padding). Style thumbnails in `DesignForm.tsx` (`StyleThumb`) are drawn from the `STYLES` tokens.
- Required fields: the schema accepts empty names (drafts autosave while typing), so `missingFields()` in `src/lib/quote/validate.ts` decides what the PDF needs (sender name, client name, at least one line, a description on every line); `Field` takes `required` for the asterisk and the builder lists what is missing next to the download buttons, which stay disabled until then. Line-item cards put number, amount and actions on one row and the fields below (two columns on phones). The colour picker in `BrandingForm.tsx` is presets with a check mark, a colour-wheel swatch that opens the native picker and a hex box; it is deliberately not inside a `Field` label. Controls are 16px on phones so iOS does not zoom.
